# LeagueStuff

Welcome to my personal league project!	This is something I spent a good amount of time on, and is comprised of some code I wrote so that I could try and analyze my League of Legends gameplay with Linear Algebra. I go over what league is and why I chose to do this project, as well as some strategies I use to interpret my data which includes Principal Component Analysis, Linear Regression, and some other bonuses like the Moore Penrose Pseudoinverse. This way I can interpret the difference between my winning and losing games and see how I can improve.
